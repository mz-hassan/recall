Key Challenges in RL
(1) Credit Assignment Problem
▶ Which actions led to a particular reward?
▶ Delayed effects make this difficult
(2) Exploration vs. Exploitation
▶ Explore: Try new actions for potentially better outcomes
▶ Exploit: Use current knowledge to maximize return
(3) Curse of Dimensionality
▶ Large/continuous state and action spaces
▶ Long horizons increase complexity exponentially
(4) Sample Efficiency
▶ Agent generates its own data
▶ Real-world interactions can be expensive
CS690S:AIAlignment(Prof.ScottNiekum) ReinforcementLearning 5/21

More Challenges
(5) Non-stationarity & Distribution Shift
▶ Policy changes ⇒ state distribution changes
▶ World may be non-stationary
(6) Reward Design
▶ Difficult to specify what we want
▶ Reward hacking: unintended solutions
(7) Partial Observability
▶ Agent may not observe full state
▶ Need memory or belief state
(8) Reproducibility & Sensitivity
▶ High variance across runs
▶ Sensitive to hyperparameters and even hardware!

Model-Based vs Model-Free
Model-Based Methods:
Use known/learned dynamics T(s,a,s′) and reward function r(s,a)
Often uses dynamic programming (Value/Policy Iteration)
Pros: Simple, exact when value function / policy is tabular
Cons: Struggles with model errors
Model-Free Methods:
Learn value function or policy from experience directly
Don’t explicitly model transition dynamics
Pros: Works with complex/unknown dynamics
Cons: Sample inefficient, high variance

Off-Policy vs On-Policy
On-Policy (SARSA):
Learns value of the policy currently being followed
π must become greedy over time, or will not converge to optimal
value function / policy (example: Cliff World)
Better convergence guarantees with linear function approximation
Update: Q(s,a) ← Q(s,a)+α[r +γQ(s′,π(s′))−Q(s,a)]
Off-Policy (Q-Learning):
Learns optimal Q∗ regardless of actions taken – can explore in any
manner or use data from any policy
More sample efficient – can reuse old data
Update: Q(s,a) ← Q(s,a)+α[r +γmax Q(s′,a′)−Q(s,a)]

Actor-Critic: Best of Both Worlds
Idea: Combine the advantages of policy search and value functions
Actor: Directly parameterized policy, as in policy search
Critic: Value function, as in VF-based methods
Properties:
Actor supports continuous actions
Critic increases sample efficiency and reduces variance of updates
Comes at the cost of additional complexity, but still popular in
practice
