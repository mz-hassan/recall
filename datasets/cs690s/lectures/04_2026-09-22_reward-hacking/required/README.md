# Saved web readings

Open the `.html` files in a browser (double-click or Open With), rather than Finder Quick Look. These saved original pages include local styles, fonts, diagrams and equation images in `_assets/`. Keep `_assets/` beside the HTML when moving these readings.

Links between the three RL readings work locally. Videos, search and links to other pages need internet. Site-wide interactive menus are not guaranteed offline. Adjacent TXT files are search aids, not additional assignments. Original URLs, asset provenance and any unavailable assets are recorded in `offline-assets.json`; the lecture README links the live sources.
