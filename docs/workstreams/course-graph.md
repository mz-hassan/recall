# Course-wide knowledge graph

Own `src/graph/`. The entry point lives on the main course page. Build an Obsidian-like graph across lecture topics.

- [ ] Build a graph harness that extracts concepts and typed relationships from multiple lectures with citations and resolves aliases and duplicate concepts.
- [ ] Store stable concept IDs and source references. Filter by lecture and relation, surface neighboring concepts, and link nodes to the lecture or moment.
- [ ] Implement an interactive graph with pan, zoom, search, visible relation labels on selection, and a keyboard-accessible list of connections.
- [ ] Evaluate a fixture across behavior cloning and reinforcement learning for deduplication, resolvable edges and source links.
